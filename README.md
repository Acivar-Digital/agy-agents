# Antigravity Agents (agy-agents)

This repository contains standalone Agentic workflows and tools designed to run against the LiteRouter API Gateway using Google's Antigravity sandbox (`antigravity-preview-05-2026`).

## Available Agents

*   **[Deep Research (Institutional Protocol)](deep-research/)**: A multi-persona research council workflow that leverages Antigravity's web-search and sandbox execution capabilities to produce heavily cited, institutional-grade whitepapers.

## Setup

These agents are designed to communicate with a local LiteRouter instance. 
Please refer to the individual agent directories for specific instructions.
